# 数据生成脚本使用说明

## 概述

本脚本用于生成UPPE训练数据集，使用拉丁超立方体采样方法覆盖指定的参数空间。脚本会运行Luna模拟，计算物理特征，并将结果保存为HDF5文件。

## 功能特性

- **拉丁超立方体采样**：均匀覆盖参数空间
- **批处理**：支持分批处理模拟，避免系统过载
- **错误处理**：即使个别模拟失败也能继续运行
- **中断恢复**：支持从中断点继续运行
- **详细日志**：记录运行状态和错误信息
- **物理特征计算**：自动计算并保存物理特征

## 参数配置

### 采样参数

脚本默认采样以下参数：

| 参数 | 范围 | 采样方式 |
|------|------|----------|
| 脉冲能量 | 0.3-3 μJ | 对数刻度 |
| 脉冲持续时间 | 5-50 fs | 对数刻度 |
| 啁啾参数 | -3 到 +3 | 线性 |
| 气体压力 | 0-50 bar | 线性 |
| 光纤长度 | 0.03-0.5 m | 线性 |
| 纤芯直径 | 10-50 μm | 线性 |

### 模拟参数

- 中心波长：1030 nm
- 波长范围：200-2000 nm
- 时间窗口：500 fs
- 保存点数：101
- 气体：氩气 (:Ar)
- 脉冲形状：sech
- 模型：full
- 损耗：true
- Raman效应：false（氩气是惰性气体，无拉曼效应）
- 等离子体效应：true

## 目录结构

运行脚本后，会生成以下目录结构：

```
training_data/
├── sample_000001.h5
├── sample_000002.h5
├── ...
├── sample_10000.h5
└── data_generation.log
```

## HDF5文件结构

每个HDF5文件包含以下内容：

- **基本模拟数据**：由Luna自动保存的模拟结果
- **物理特征**：在`physics_features`组中
  - `beta2`：色散参数
  - `gamma`：非线性系数
  - `N`：孤子阶数
  - `L0`：色散长度
  - `gamma_K`：Keldysh参数
  - `P_ratio`：峰值功率与自聚焦临界功率之比
  - `Aeff`：有效模场面积
  - `neff`：有效折射率

## 使用方法

### 本地运行

1. 确保已安装Luna.jl及其依赖
2. 进入脚本所在目录
3. 运行以下命令：

```bash
julia data_generation.jl
```

### 云端运行

1. **连接到云端环境**：
   ```bash
   ssh your_username@cloud_server
   ```

2. **上传脚本**：
   ```bash
   scp data_generation.jl your_username@cloud_server:/path/to/luna/examples/simple_interface/
   ```

3. **后台运行**：
   ```bash
   nohup julia data_generation.jl > data_generation.out 2>&1 &
   ```

4. **监控进度**：
   ```bash
   tail -f data_generation.out
   # 或查看日志文件
   tail -f training_data/data_generation.log
   ```

## 配置调整

### 修改模拟数量

编辑脚本中的`TOTAL_SIMULATIONS`变量：

```julia
const TOTAL_SIMULATIONS = 10000  # 目标模拟数量
```

### 修改批处理大小

编辑脚本中的`BATCH_SIZE`变量：

```julia
const BATCH_SIZE = 100  # 每批模拟数量
```

### 从中断点恢复

编辑脚本中的`START_INDEX`变量：

```julia
const START_INDEX = 5001  # 从第5001个采样点开始
```

## 性能考虑

- **内存**：每个模拟需要一定的内存，批处理大小应根据可用内存调整
- **CPU**：模拟是CPU密集型的，建议在多核系统上运行
- **存储**：10,000个模拟会生成约10-20GB的数据，确保有足够的存储空间
- **时间**：每个模拟可能需要几秒钟到几分钟，具体取决于参数和硬件性能

## 故障排除

### 常见错误

1. **内存不足**：减少批处理大小
2. **权限错误**：确保有写入输出目录的权限
3. **依赖缺失**：确保已安装所有必要的依赖包
4. **模拟失败**：脚本会记录失败的模拟并继续运行，查看日志文件了解详情

### 日志文件

日志文件`data_generation.log`包含详细的运行信息，包括：
- 开始和结束时间
- 每个模拟的参数和状态
- 错误信息（如果有）
- 批处理进度

## 数据使用

生成的数据可用于：
1. 训练前向代理模型
2. 研究参数空间中的物理现象
3. 验证逆设计工具
4. 分析不同参数对输出光谱的影响

## 注意事项

- 生成10,000个模拟可能需要数天时间，具体取决于硬件性能
- 建议在后台运行脚本，避免终端会话中断
- 定期检查日志文件，确保脚本正常运行
- 如有必要，可调整参数范围和采样策略以适应特定研究需求
