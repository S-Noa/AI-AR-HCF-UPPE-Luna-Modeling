# HCF MLP 模型项目完整技术报告

## 1. 项目概述

本项目实现了一个基于多层感知机(MLP)的气体填充空芯光纤(HCF)超连续谱预测模型，旨在替代耗时的UPPE数值模拟，实现毫秒级光谱预测。

- **核心功能**：参数输入 → 模型预测 → 光谱可视化
- **技术栈**：PyTorch、PyQt5、NumPy、Matplotlib
- **模型性能**：R²=0.9227，MSE=0.0018

## 4. 模型架构

### 4.1 网络结构

```
Input (13 features) → Linear(256) → BatchNorm → LeakyReLU(0.01) →
Linear(512) → BatchNorm → LeakyReLU(0.01) →
Linear(512) → BatchNorm → LeakyReLU(0.01) → Dropout(0.1) →
Linear(256) → BatchNorm → LeakyReLU(0.01) →
Output (500 spectral points)
```

- **总参数量**：约660K
- **训练样本**：10,000+
- **训练时间**：约30分钟（GPU）

### 4.2 输入特征

| 特征 | 类型 | 说明 |
|------|------|------|
| energy | 可控 | 脉冲能量 (μJ) |
| tau | 可控 | 脉冲宽度 (fs) |
| pressure | 可控 | 气压 (bar) |
| length | 可控 | 光纤长度 (cm) |
| diameter | 可控 | 纤芯直径 (μm) |
| beta2 | 计算 | GVD β₂ (fs²/mm) |
| gamma | 计算 | 非线性系数 γ (1/(W·m)) |
| N | 计算 | 孤子阶数 |
| L0 | 计算 | 色散长度 L₀ (cm) |
| gamma_K | 计算 | Keldysh参数 |
| P_ratio | 计算 | 峰值功率/临界功率 |
| Aeff | 计算 | 有效模面积 (μm²) |
| neff | 计算 | 有效折射率 |

## 5. 系统架构

### 5.1 数据流

1. **参数输入**：用户输入5个可控参数
2. **参数计算**：自动计算8个物理参数
3. **数据预处理**：映射到[0,1]归一化空间
4. **模型推理**：MLP模型预测500点光谱
5. **结果可视化**：绘制光谱图，显示预测信息

### 5.2 模块关系

- **GUI模块**：用户交互界面
- **推理模块**：模型加载和预测
- **可视化模块**：光谱绘制和数据展示
- **数据处理模块**：参数计算和归一化

## 6. UPPE仿真流程

### 6.1 仿真步骤

1. **初始化**：设置仿真环境和参数
2. **脉冲定义**：定义输入脉冲的形状和参数
3. **光纤参数**：设置光纤几何参数和气体属性
4. **非线性传播**：求解UPPE方程
5. **光谱计算**：从时域信号计算频域光谱
6. **输出**：保存和分析结果

### 6.2 计算复杂度

- **时间复杂度**：O(N³)，其中N是时间/频率网格点数
- **典型仿真时间**：数分钟到数小时
- **MLP替代**：毫秒级推理
